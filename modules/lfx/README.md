# 目录壳（对比用）

双击 `web/index.html` 即可在 `file://` 下浏览。数据来自 `web/data/links.js`（普通脚本 `window.LINKS`），页面不 `fetch` 本地文件。

重新生成：

```bash
python3 scripts/build_links_js.py
```

脚本只读 `handoff/links-seed-2026-11-24.json`、`catalog/series.json` 和 `original/ep*.md`，不访问网络。同样的输入跑两次，`web/data/links.js` 字节一致。

外链用底表里的 `page_url`，不改写。分页必须用查询格式 `?&page=N`，路径格式会被静默忽略。卡底四个链接不写入底表，只在对应 `parts` 为真时拼出来：Quiz 用 `https://chinese.littlefox.com/en/quiz/main/`，Words 用 `https://chinese.littlefox.com/en/supplement/vocabulary/`，Game 用 `https://chinese.littlefox.com/en/starwords_h5/main/`，Print 用 `https://chinese.littlefox.com/en/supplement/printable_book/`，后面都加该集 `c_code`。无 Quiz 的 4 集是 C0006949、C0006950、C0006951、C0006986（DP000777）。这四类地址需要登录，未登录时返回登录提示，不把 200 当成内容已打开。

三个系列的标称集数和当前可访问集数不同，两个数都保留：DP000746 标 44、现有 20；DP000753 标 60、现有 47；DP000799 标 48、现有 42。界面写成「标 44，现有 20 可访问」这种形式。其余系列只显示可访问集数。没有英文标题的集显示「—」，不补译。

语音前置 6 个系列在底表中的级别是 L1。首页另给一个入口，L1 卡片仍是底表的 14 系列 / 459 集。

自建课只显示目录卡（系列名与篇数来自 `original/`），没有课程页。

缩略图使用底表中的原地址。加载失败时用灰底书脊显示集号或系列名首字，不新增图片，也不把原图写入仓库。

底部有首页、进度、关于、语言。已看勾选记在本机，最多 3 个读者，互不影响。新勾选记下本地日期 `YYYY-MM-DD`；旧记录只有「看过」、没有日期，导出时 `date` 写 `null`，不删旧进度，近 7 天仍用单独的日期表。界面一次只显示一种语言，默认英文，可切泰文或中文。故事标题仍是英文加中文。宽度小于 600px 时卡片一列，600px 及以上两列。

进度页可导出学习记录，只在本机生成文件，不上传。可选当前读者或全部读者。每行一条已勾选记录，字段依次是 `reader,date,level,dp_code,series_title_en,n,c_code,title_en,title_zh,seen`。`seen` 为 `true` 或 `false`。文件名是 `story-steps-record-YYYYMMDD.csv` 或同名 `.json`。

`manifest.json` 使用 `display: standalone`。浏览器不支持从 `file://` 安装到主屏幕；用本地静态服务打开后，可以从浏览器菜单添加。服务线程只在 http 或 https 下注册，并且只缓存本站文件。缓存名是 `shell-v6`。若托管把 `/signup.html` 跳到 `/signup`，存缓存和返回前会去掉跳转标记；导航优先用网络，失败再用缓存，`/x` 与 `/x.html` 视为同一页。`file://` 不注册服务线程。

外链需要用户在官方站自行登录。本应用不做账号、不存密码、不向对方发请求。

已定：注册页地址为 https://chinese.littlefox.com/en/user/join（2026-11-25 经 Milo 提供，同日审查方改为公开注册页）。引导页上的注册按钮指向该地址。首页和系列页的「第一次用？先免费注册」仍进入本站 `signup.html`。`/en/user/join_form` 为内部端点，直接打开会 Access Error，勿用。

外链验收口径：新增外链须三看——状态码、字节数、正文关键字段（标题或表单字段名），由审查方执行。

## 设计系统

方法参照公开的 UI UX Pro Max：先定产品类型，再定风格、配色、字体、间距和交互，然后才改界面。下面是本产品自己的决定，没有把那套资料拷进仓库。

- 产品类型：给儿童和青少年用的外语分级阅读目录。相近类型是语言学习、儿童学习和阅读书架。那些类型里常见的积分、徽章、排行，本产品明确不用。
- 风格：大圆角卡片加平涂色块，一屏一件事。不做玻璃拟态，不用大面积紫或靛蓝。
- 配色（浅色）：纸色 `#FFF6EC`，卡片白 `#FFFFFF`，正文 `#1A2332`，次文 `#3C4A5E`，主按钮 `#0E6B57` 上白字。深色可选：底 `#10161C`，卡片 `#1A232D`，正文 `#F6F3EE`，次文 `#D5DCE4`，主按钮 `#146B5A` 上白字。正文对比度按 WCAG AA（至少 4.5:1）核对过。
- 字体：只用系统字体栈，不加载远程字体。标题约 1.35rem、字重 750；泰文行高 1.6。界面文案三行：所选语言是大字主行，其余两行更小。默认英文主行、泰文副行、中文最弱。
- 间距与触控：8px 网格，圆角 20px，可点目标在三档都至少 44px。按下只改不透明度，不挪动布局。`prefers-reduced-motion: reduce` 时关掉动效。
- 断点三档：
  - 手机，宽度小于 700px（约 390 宽）：级别卡 1 列，故事卡 2 列，页边 16px，导航贴在底部。
  - 平板，700px 到 1279px。竖屏约 820 宽：级别卡 2 列，故事卡 3 列，页边 28px，导航仍在底部。横屏约 1180 宽：级别卡 3 列，故事卡 4 列，导航改到左侧竖条，腾出横向阅读区。
  - 桌面，1280px 及以上：级别卡 3 列，故事卡 4 列，页边 40px，导航在左侧。
- 故事标题只显示数据里已有的英文（主）和中文（辅）。没有泰文标题，界面不留空位。
- 缩略图只用原地址引用，失败时显示自己画的书本占位，不把图片写入仓库，服务线程也不缓存跨域图片。
